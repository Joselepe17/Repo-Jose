Elementos de un formulario web

HTML ofrece diferentes controles de formulario para que los usuarios puedan introducir, seleccionar y enviar información. Aqui tienes todos los tipos principales con ejemplos.

Campo de texto

Permite escribir una línea de texto <input type="text">

Contraseña

Texto oculto por seguridad <input type="password">

Correo electrónico

Para direccciones de email <input type="email">

Número

Permite introducir números <input type="number">

Teléfono

Para números de teléfono <input type="tel">

URL

Para direcciones web <input type="url">

Búsqueda

Campo de búsqueda <input type="search">

Fecha

Permite introducir fechas <input type="date">

Hora

Selector de hora <input type="time">

Semana

Selector de semana <input type="week">

Mes

Selector de mes <input type="month">

Fecha y hora

Selector de fecha y hora <input type="datetime-local">

Color

Permite introducir colores <input type="color">

Rango

Permite introducir valores dentro de un rango <input type="color">

Checkbox

Permite una selección múltiple <input type="checkbox">

Radio

Permite una selección múltiple <input type="radio">

Lista despegable

Permite seleccionar una opcion en una lista <select">

Area de texto

Permite incluir texto en vareas líneas <textarea">

Lista de datos

Permite sugerencias <input list="Provincias">

Subida de archivos

Seleccionar <input type="file">
