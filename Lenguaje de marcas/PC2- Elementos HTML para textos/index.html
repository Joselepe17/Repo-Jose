El lenguaje de la Web

HTML es el lenguaje que utilizamos para estructurar los contenidos de una página web. El término HTML significa HyperText Markup Language.

Una de las características más interesantes de HTML5 es que permite describir mejor el significado de los contenidos. Por ejemplo, cuando hablamos de un término que queremos definir, podemos utilizar una etiqueta específica.

El concepto de accesibilidad web hace referencia a la posibilidad de que cualquier persona pueda utilizar una página web, independientemente de sus capacidades.

La obra The Timeless Way of Building, de Christopher Alexander, es una referencia interesante cuando hablamos de diseño y estructura.

En una página web también podemos mostrar pequeños fragmentos de código, como document.querySelector("h1").

Supongamos que una entrada de nuestro catálogo tenía anteriormente un precio de 29,99 €, pero actualmente cuesta 24,99 €.

También podemos indicar que una característica ha sido añadida recientemente: Modo oscuro disponible.

HTML permite además mostrar información que puede ser útil para las máquinas. Por ejemplo, el producto tiene el código A001 y su precio es veinticuatro con noventa y nueve euros.

Como dijo Tim Berners-Lee:

La Web es más una creación social que técnica. La diseñamos para que tenga un efecto social, para que ayude a las personas a trabajar juntas.

También podemos incluir una cita breve dentro de un párrafo. Por ejemplo, Berners-Lee afirmó que la Web debía ser un espacio abierto y universal.

Si queremos ampliar la información sobre HTML, podemos ocultar inicialmente algunos datos y permitir que la persona usuaria los muestre cuando quiera.

Información adicional sobre HTML: HTML no es un lenguaje de programación, sino un lenguaje de marcado que permite estructurar documentos.
